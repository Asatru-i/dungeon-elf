# 🧝 Dungeon Elf

Пиксельный рогалик про эльфа и вечную осень.

Ты спускаешься в подземелье, чтобы остановить Архимага Тириона — он врос в корень жизни и стал Древнем. Он хотел остановить смерть. Он забыл, что смерть — часть жизни.

---

## 🎮 Как играть

**Один файл.** Открой `index.html` в браузере — и играй.

**Управление:**
- **WASD / стрелки** — движение (на телефоне — джойстик слева)
- **Пробел** — атака (на телефоне — кнопка 🔥)
- **E** — способность подкласса
- **Shift** — рывок
- **1** — выпить зелье
- **B** — сумка

---

## ⚔️ Что внутри

- 25 этажей с разными биомами
- 3 класса × 9 подклассов
- Наземные локации: деревня, лес, замок
- 5 режимов: Классика, Скорость, Хардкор, Бесконечный, Проклятый
- Сюжет через дневники Аэлиса, Старейшины и других
- Метапрогрессия: банк, улучшения, навыки, крафт
- Бестиарий, справочник, кодекс

---

## 🛠️ Технически

- Чистый HTML + CSS + JavaScript
- Canvas 2D для рендера
- Web Audio API для звука
- localStorage для сохранений
- Без библиотек и фреймворков
